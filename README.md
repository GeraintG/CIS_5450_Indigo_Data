# CIS_5450_Indigo_Data
Can historical checkout information from 2024–2025 predict long-duration rides in a later operating period in 2026?

## Geographic Data Source

- [Philadelphia Planning Districts metadata](https://metadata.phila.gov/#home/datasetdetails/5543864620583086178c4e7d/representationdetails/55438a839b989a05172d0cfd/) — City of Philadelphia boundaries for the 18 Philadelphia2035 planning districts, used to map station locations to planning districts.
